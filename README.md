# 🎭 SauceDemo E2E Automation with Playwright

An automated end-to-end (E2E) testing project for the [SauceDemo](https://www.saucedemo.com/) web application using **Playwright**. This suite covers critical user journeys such as authentication, inventory browsing, cart management, and checkout processing.

---

## 🚀 Features

* **Cross-Browser Testing:** Automated execution across Chromium, Firefox, and WebKit (Safari).
* **Parallel Execution:** Fast test runner execution powered by Playwright.
* **Rich Reporting:** Built-in HTML reports with screenshots and video artifacts on test failure.

---

## 🛠️ Tech Stack

* **Framework:** [Playwright](https://playwright.dev/)
* **Language:** JavaScript / TypeScript
* **Node.js:** v18+ recommended

---

## 📋 Prerequisites

Before running the tests, ensure you have the following installed:
* [Node.js](https://nodejs.org/) (version 18 or higher)
* [Git](https://git-scm.com/)
